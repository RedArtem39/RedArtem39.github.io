# Artem's portfolio

Static portfolio for [RedArtem39.github.io](https://redartem39.github.io/). GitHub Pages serves the root of the `main` branch. There is no build step.

## Edit the site

- Content and project links: `index.html`
- Layout, colors, responsive styles: `styles.css`
- Images and locally hosted Geist font: `assets/`

Run a local static server from this directory to preview the site. For example:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

The hero image was generated for this site. Project images come from the WynlandOS and Efir repositories. Geist is distributed under the SIL Open Font License 1.1.
